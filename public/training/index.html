For Dispatch — How Readiness Records Work

  • Every module ends with a scored completion summary (driver name, module, score, date). The driver screenshots it and sends it to dispatch.
  • File summaries as the driver's readiness record. Suggested standard: 80% or better to pass a module; below that, the driver re-runs it.
  • Summaries prove preparation, not certification. Required credentials — HIPAA course completion, pilot car certification where a state requires it — still come from recognized providers and go on the same driver file.
  • Suggested gate: Modules 1–3 passing summaries + HIPAA certificate on file before a driver's first paid medical run.
